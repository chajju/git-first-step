## 실행 방법
`index.html` 파일을 더블클릭해서 브라우저로 열면 돼요. (별도 설치 필요 없음)

## 파일 구성
- `index.html` — 화면 구조와 문구
- `style.css` — 색상, 크기 등 디자인
- `script.js` — '확인' 버튼 동작
